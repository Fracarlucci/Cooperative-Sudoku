# Cooperative Sudoku

## Part1

Concurrent program to execute agent-based simulations implemented with actors.

## Part2A

Cooperative multiplayer sudoku implemented with a decentralized architecture based on message passing, using MOM (Message-Oriented Middleware).

## Part2B

Cooperative multiplayer sudoku implemented with a centralized architecture based on Distributed Object Computing, using Java RMI.

## Part3

Guess the number in Go implemented with synchronized message passing.
